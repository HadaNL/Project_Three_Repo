About the Game

This Way That Way was inspired by the ghost race from Ghost Carnival Project.
We took the idea of the race and made the race a 2-player game.
Additionally, a second level that requires team work was added to the project.

During development I added zones which i would be able to use to make boundaries.
Additionally, the zones helped when i wanted to have certain things happen
the map in specific zones.

The process was started in Illustrator and after completing a few zones it was
continued in VS Code The Zones are a class which
includes their position, color value, name, and the opacity.

The last three images show the process and a small portion of code for the zones.

Along with working on Code. I also, wanted to attempt to make pixel art.
I used a website called pixilArt, where I made the characters above.

I also worked on a spriteSheet and after I was done I decided to have drawings
for all the different winning possibilities. Each character has 12 drawings,
but then i realized that in our game we allow mirror matches, and so I
made a few more drawings.
